# HTTPとは何か

Hyper Text Transfer Protocol

## おさらい

API = プログラムが別のプログラムの機能やデータを利用するための接点・ルール

Web APIは、そのAPIをWebの仕組みを使って利用できるようにしたもの。

ここで登場するのがHTTP。

## HTTP

> Web上で、クライアントとサーバーが情報をやり取りするための通信ルール

- どういう形式で「お願い」するのか
- どういう形式で「返事」をするのか
- どういう意味のメッセージなのか
- 成功したのか、失敗したのか

などを決めているのがHTTPという通信のルール。

HTTP = 通信そのもではない。

HTTPは、Web上で情報をやり取りするために、クライアントとサーバーが従うルール(プロトコル)

=> プロトコル: 約束事

共通のルール・約束事の上で通信を行うことで、異なるメーカー、OS、プログラム同士であっても通信ができる。
