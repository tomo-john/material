# APIとは何なのか？

> 別のサービスやプログラムにお願いするための窓口(接点)

=> APIは単にデータを渡す仕組みだけではない。

- どんな機能を提供する？
- どうやって呼び出す？
- 何を渡す？
- 何が返ってくる？

のような取り決めそのものがAPI。

このAPIをこのルールで呼べば、この結果が返ってくる。

=> 異なるプログラム同士がお互いの内部構成を知る必要がない

APIはプログラム同士が機能やデータを利用・交換するために定められた接点やルール。

APIと聞けば、一般的にはWeb APIが有名だが、あくまでAPIという概念の中にWeb APIがいる。

```bash
API
  |
  |- Web API
  |
  |- OS API
  |
  |- Library API
  |
  |- Database API
  |
  |- その他いろいろ
```

## APIって誰かにお願いするものだけののか？

PHPメソッドで、`strlen('hello');`と書いたとき、これはAPIと呼べるのか？

> strlen() 自体が「APIを利用している」というより、strlen() という関数そのものが、PHPが提供しているAPIの一部

PHPを使う側からすると、`strlen() -> 文字列の長さを教えて下さい`とPHPにお願いしている。

- 関数名は`strlen`
- 引数には文字列を渡す
- 戻り値は整数

という決められたルールがある。これがインターフェース的な部分。

PHP側がこの外部から利用するための決まりを提供している = PHPのAPIと考えられる
