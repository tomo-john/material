# フロントエンドとバックエンド

フロントエンドとバックエンドって、そもそも何を境界に分かれているのか？

```
ブラウザ -> ??? -> Laravel -> DB
```

=> この???は何なのか？

また、通常(?)のBladeを使用しているLaravel(フロントエンドとバックエンド分けてない)において、

フロントエンドはどこまでで、バックエンドはどこからなのか？

## まずそれぞれの意味

- フロントエンド: ユーザーが直接触れる部分
- バックエンド: ユーザーから直接見えないところで、データや処理を担当する部分

```bash
Laravel
│
├── Routing       ← バックエンド側の入口
├── Controller    ← バックエンド
├── Service       ← バックエンド
├── Model         ← バックエンド
├── Database      ← バックエンド
│
└── Blade         ← HTMLを作る部分
```

> BladeはサーバーサイドでHTMLを生成する「ビューの仕組み」

Bladeを使用するLaravelの場合、明確なフロントエンドとバックエンドの堺がない。(定義が難しい...)

> フロントエンドとバックエンドは、Laravelのフォルダ構成で機械的に分ける概念ではない。
> 「ユーザー側でUIを扱う部分」と「サーバー側で処理・データを扱う部分」という役割の分担として考える。

## Web APIの場合

```bash
Frontend: HTTP Request
    |
Laravel API: Service -> JSON
    |
Frontend: JSONからHTML生成・表示
```

この場合:

- Frontend: React, Vue
- Backend: Laravel, PHP, DB

のように明確に分離しやすくなる。
