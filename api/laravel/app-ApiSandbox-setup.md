## Invalid URI: Host is malformed. 

> Symfonyの HttpFoundation\Request が、URIのhost部分を不正と判断したときに投げるエラー

らしい。

プロジェクト作成後に、`php artisan --version`しすると、`Invalid URI: Host is malformed.`が出た。

今回の原因は`.env`の`APP_URL=http://localhost:8000:8000`が原因だった。

ここを、`APP_URL=http://localhost:8000`に修正すると`artisan`コマンド使えた。

## MySQLの設定メモ(Windows WSL2/Ubuntu)

### ApiSandbox用のDBとユーザーを作成

```bash
sudo mysql # MySQLコンソールに入る

# 以下mysql> コンソールにて

CREATE DATABASE apisandbox;                                             # DB作成

CREATE USER 'apisandbox_user'@'localhost' IDENTIFIED BY 'password1234'; # ユーザー作成

GRANT ALL PRIVILEGES ON apisandbox.* TO 'apisandbox_user'@'localhost';  # apisandbox DBの操作権限付与
```

### Laravel側の .env を編集

```bash
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=apisandbox
DB_USERNAME=apisandbox_user # ここ
DB_PASSWORD=password1234    # ここ
```

ここまでやって、`php artisan migrate`
