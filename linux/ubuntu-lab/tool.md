# ツール導入(初期)

```bash
sudo apt install -y \
git \
curl \
wget \
tree \
tmux \
btop \
zip \
unzip
```

それぞれの役割:

| コマンド | 用途                   |
| -------- | ---------------------- |
| git      | Git管理                |
| curl     | HTTP通信               |
| wget     | ファイルダウンロード   |
| tree     | ディレクトリ木構造表示 |
| tmux     | セッション管理         |
| btop     | CPU メモリ管理         |
