# JSON

> データを一定のルールに従って表現するための形式

正式名称は、`JavaScript Object Notation`

=> 名前にJavaScritpが入ってるけど、JSON = JavaScriptのものではない

=> 現在はプログラミング言語をまたいで使われる汎用的なデータ形式(として広く使われている)

JSON = データではなく、あくまでデータを表現するための形式。

コンピュータ同士でデータをやり取りする時の、「どんな構造でデータを表現するか」という共通のルール。

## なぜAPIではJSONがよく使われるのか？

APIでデータそのものを渡したい(受け取りたい)とき、異なるプログラミング言語同士でもそのデータを読み取って利用できる。

なので、Web APIではJSONが非常によく使われている。

## API = JSONではない

Web APIのデータの受け渡しにJSONがよく使われるが、APIそのものがJSONなのではない。

よく使用はされるが、APIが必ずJSONを扱うわけではない。

`XML`, `HTML`, `その他の形式`など、他のデータ形式でデータをやりとりすることもある。

## PHP配列とJSONの違い

PHP配列:

```php
<?php
$data = [
    'id' => 123,
    'title' => 'HTTPとは何か',
    'status' => 'practice',
];
```

JSON:

```json
{
    "id": 123,
    "title": "HTTPとは何か",
    "status": "practice"
}
```

=> 似ている

### 大事な違い

PHP配列は、PHPプログラムの中でデータを扱うためのもの。

JSONはプログラム間でデータをやり取りしやすいようにデータを表現するための形式。

```text
PHP配列 --- ( json_encode() ) ---> JSON --- ( HTTPなどで通信 ) ---> 別のプログラム
```

ちなみに、JSONという「データ形式」で表現されたものを、PHPでは文字列として扱っている。
