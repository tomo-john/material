# ステータスコード

参考ULR: [HTTPレスポンスステータスコード](https://developer.mozilla.org/ja/docs/Web/HTTP/Reference/Status)

> サーバーがHTTP Requestを処理した結果を、クライアントに伝える為の3桁の数字

## なんで数字なのか

そもそもの`HTTP`は異なるコンピュータやプログラム同士が共通のルールで通信するためのもの。

HTTPは共通のルールに基づいたコードを使用することで、わかりやすく表現をした。

## 3桁の数字の大まかなグループ

先頭の数字(1-5)で大まかな意味がわかる。

| 範囲 | 大まかな意味               |
| ---- | -------------------------- |
| 1xx  | 情報                       |
| 2xx  | 成功                       |
| 3xx  | リダイレクト               |
| 4xx  | クライアント側の要求に問題 |
| 5xx  | サーバー側の問題           |

## 代表的なステータスコード

### 200番台

| コード | テキスト   | 意味                    |
| ------ | ---------- | ----------------------- |
| 200    | OK         | Requestを正常に処理した |
| 201    | Created    | 作成成功                |
| 204    | No Content | 成功したけどBodyなし    |

### 400番台

| コード | テキスト      | 意味                 |
| ------ | ------------- | -------------------- |
| 400    | Bad Request   | Requestがおかしい    |
| 401    | Unauthorized  | 認証が必要           |
| 403    | Forbidden     | 権限がない           |
| 404    | Not Found     | 見つからない         |
| 422    | Unprocessable | 内容に問題がある     |

### 500番台

- 500 Internal Server Error — サーバー側の問題
