# mac-sub 🐶

MacBook Pro で行う **サブ学習** 用のディレクトリです。

## 位置づけ

| 項目 | 内容 |
|---|---|
| メイン学習 | Windows 11 ノートPC(Claude Code が先生役・学習記録係) |
| サブ学習(ここ) | MacBook Pro(Claude Code の先生🐶がサポート) |
| 目的 | メイン学習の復習・補足・寄り道。進捗の管理はメイン(Windows 側)で行う |

- このディレクトリは Mac での学習専用
- Windows 側の学習では、基本的にここを触る必要はない

## 先生とのルール

### 読み取り

- `cpp-qt5-study/` 以下のファイルはすべて読んでOK
- 必要に応じて Windows 側の学習状況(ロードマップ、レッスン、課題、コード)を把握したうえでサポートする

### 書き込み

- 書き込み(新規作成・更新)してよいのは`mac-sub/` 以下のみ
- `mac-sub/` 以外のファイルは変更しない

### プロジェクト作成・コード編集

- 学習のため、プロジェクトの作成やコードの編集は基本的に自分で行う
- 先生は、ヒント・解説・レビューでサポートする
- 作成や編集をお願いしたときだけ、先生が行う -> その場合も実行前に内容を確認してから進める

## ディレクトリ構成

```
mac-sub/
├── README.md          このファイル
├── docs/
│   ├── ROADMAP.md     Mac でのサブ学習の計画と進捗
│   ├── setup-mac.md   Mac の環境構築メモ
│   └── lessons/       レッスン資料（予定）
└── projects/          Mac で作った Qt / C++ プロジェクト
```

学習の計画と進捗は [docs/ROADMAP.md](docs/ROADMAP.md) を参照。

## Git について

- リポジトリは Windows 側と共通(GitHub のプライベートリポジトリ)
- それぞれのPCでは最後にpush・最初にpull -> 競合を起こさないために同時で作業はしない
